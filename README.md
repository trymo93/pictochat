# ✏️ PictoChat

Chat con disegni a mano libera stile PictoChat del Nintendo DS, che funziona
**offline** tra telefoni sulla stessa rete (hotspot) — perfetta in aereo.

**Apri l'app:** https://trymo93.github.io/pictochat/

Come si usa: prima del volo ognuno apre il link e lascia la scheda aperta.
In volo: modalità aereo, uno accende l'hotspot, gli altri si collegano a quel
Wi-Fi, poi "Crea il gruppo" / "Unisciti" e ci si inquadra i QR a vicenda.

Il codice completo (con anche la versione con server) è nel repo privato
`codingStuff`, cartella `pictochat/`.
